# Insightly

[Open Insightly](https://insightly.space)

Insightly is a data-collection tool for a research project I am running. Its goal is to help researchers create question banks, collect responses, view useful statistics, and access and download data to support their conclusions.

This public repository contains the exported frontend build. The underlying server code and database are separate from the files here.

**Technologies:** React, JavaScript, CSS, and Supabase (frontend build).
