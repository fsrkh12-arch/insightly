# Insightly production build

This repository contains a copy of the production frontend currently served by Vercel for Insightly.

## Live website

[Open Insightly](https://insightly.space)

[Open this GitHub copy](https://fsrkh12-arch.github.io/insightly/)

## Contents

- `index.html` — deployed application entry page
- `assets/` — production JavaScript and CSS bundles served by Vercel

This is the deployed client build. Private Vercel environment values, server-only code, database data, and deployment credentials are not included.

The public copy deploys automatically through GitHub Pages.
